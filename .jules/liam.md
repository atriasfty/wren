## 2025-03-08 - Fix Express Stack Trace Leak
**Vulnerability:** Information Disclosure
**Learning:** By default, Express returns HTML pages containing full stack traces when unhandled exceptions occur or when middleware like `body-parser` throws a `SyntaxError` on malformed JSON. This can expose internal application paths, Node.js version, and potentially sensitive environment variables or configurations to an attacker.
**Prevention:** Always implement an error-handling middleware immediately after `express.json()` to catch malformed JSON errors and return a generic 400 response. Furthermore, ensure a global catch-all error handler is placed at the very end of the route definitions to catch any other unhandled exceptions, log them server-side, and return a generic 500 JSON response. Crucially, the error handler must define all four parameters `(err, req, res, next)` to be recognized by Express as an error handler, and it must check `if (res.headersSent) return next(err);` to avoid errors when the response has already been partially sent.
