## 2025-02-19 - Express stack trace leak via unhandled exceptions and JSON SyntaxError
**Vulnerability:** Express by default leaks HTML formatted stack traces to the client when a thrown error reaches the end of the middleware chain (or when body-parser throws a SyntaxError for malformed JSON).
**Learning:** This is a common and high-risk vector for leaking internal package versions, server paths, and potentially secrets if they end up in error messages.
**Prevention:** In Express API servers, ensure a custom error handler is placed immediately after `express.json()` to catch `SyntaxError` (status 400) on malformed JSON payloads. Also, ensure a global catch-all error handler is placed at the route boundary to catch unhandled exceptions, log them server-side, and return a generic `500 Internal server error`. Crucially, include `if (res.headersSent) return _next(err);` before sending the response, and define 4 parameters `(err, req, res, _next)` for the middleware to be recognized.
