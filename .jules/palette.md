## 2024-05-24 - Interactive Element Focus & Label Semantics
**Learning:** In this application's dark-theme Tailwind configuration, interactive elements (especially standard inputs like `<input type="range">` and `<summary>` tags) often lack default keyboard focus indicators, rendering them invisible to keyboard-only users. Furthermore, form labels don't automatically trigger interactive cursor states.
**Action:** Always explicitly include `focus-visible` utility classes (e.g., `focus-visible:ring-2 focus-visible:ring-primary focus-visible:ring-offset-2 focus-visible:ring-offset-background-dark`) to ensure keyboard accessibility without degrading mouse click UX. Ensure form controls are properly associated with their labels via `for` attributes, and add `cursor-pointer` on labels to reinforce interactivity.
