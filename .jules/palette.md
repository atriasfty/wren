## 2026-08-03 - Interactive Element Accessibility in Dark Theme
**Learning:** In this application's dark theme, native interactive elements (like range inputs, buttons, and summary tags) lack sufficient default keyboard focus indicators. Furthermore, custom form controls like sliders are frequently missing explicit `<label>` associations via the `for` attribute, hindering screen reader support.
**Action:** Always explicitly include `focus-visible` utility classes (e.g., `focus-visible:ring-2 focus-visible:ring-primary focus-visible:ring-offset-2 focus-visible:ring-offset-background-dark`) on interactive elements to ensure keyboard accessibility. Ensure all form controls are associated with their labels via `for` attributes and include `cursor-pointer` on labels to reinforce interactivity.
