## 2026-07-24 - Express Error Handling\n**Vulnerability:** Unhandled JSON syntax errors and API boundary exceptions leak internal stack traces to the client and can cause the process/request to hang or crash.\n**Learning:** Express error handlers must have exactly four arguments (err, req, res, next). A specific handler immediately after express.json() can intercept 400 SyntaxErrors and return a sanitized response, but must call next(err) for unrelated errors. A global catch-all at the end of routes acts as a safety net.\n**Prevention:** Always place a 4-arity error handler at the end of Express routing chains and immediately after body parsers.
