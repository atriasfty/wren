# Features Overview

Wren is packed with awesome capabilities to make your community and gaming experience better. Let's take a look at what Wren can do!

## 🧠 Proactive Memory
Wren is not forgetful. When you tell Wren something important about yourself, or when you outline rules for your server, Wren saves these facts in its memory. This means you don't have to repeat yourself over and over.

{% hint style="success" %}
**How it works:** Under the hood, Wren uses a special "Save Memory" tool. It automatically figures out what is worth remembering and securely stores it!
{% endhint %}

## 💬 Real-Time Knowledge (RAG)
Wren pays attention to the conversations in your Discord server. If someone asks a question that was just answered by another person in a different channel, Wren can use that context to give a perfect answer. We call this real-time knowledge ingestion.

* Wren reads messages that have at least 3 words and 15 characters.
* It ignores pure links and short spam.
* It updates its knowledge base instantly if a message is edited or deleted.

## 🎮 Roblox In-Game Integration
You can actually chat with Wren while you are playing Roblox games like ERLC! Wren connects directly to your private messages in the game. It even remembers the context of your conversation for up to 5 minutes between messages, so you can have a natural, multi-turn chat without losing the thread.

## 🔍 Smart Web Search
When Wren doesn't know the answer right away, it can browse the web using the Brave Search integration. It will look up the information, read the results, and summarize the best answer for you.

## 📊 Analytics and Observability
For server owners, Wren is completely transparent. It uses PostHog to track exactly how much it is being used, how fast it responds, and how many tokens it consumes. This helps us ensure Wren stays lightning fast!
