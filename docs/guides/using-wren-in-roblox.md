# Using Wren in Roblox

One of the coolest features of Wren is that it can talk to you directly inside of Roblox games! If you play games like Emergency Response: Liberty County (ERLC), you can use the Private Message (PM) system to chat with Wren.

## Getting Connected

Wren uses a system called Bloxlink to figure out who you are. This means your Discord account needs to be linked to your Roblox account. Once that is set up, Wren knows exactly who is sending the message!

## How to send a message

When you are in the game, simply use the game's Private Message feature to send a text to Wren. 

{% hint style="info" %}
Wren will reply to you directly in the game chat! It might take a couple of seconds for Wren to think about the answer, so be patient.
{% endhint %}

## Multi-Turn Conversations

Wren is smart enough to hold a conversation with you. If you ask Wren a question, and then ask a follow up question, Wren remembers what you were talking about! 

**Here is the rule:** Wren will remember the context of your conversation for up to 5 minutes after your last message. If you wait longer than 5 minutes, Wren will start a brand new conversation with a clean slate.

Enjoy having a smart assistant right there with you while you game!
